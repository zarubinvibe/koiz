сделать, прежде чем сделать, и останавливается там, где выбор ваш.

## Как этим пользоваться

Откройте папку проекта в Claude Code, Codex или другом агенте и скажите: «проведи онбординг».
Агент идет по шагам ниже, произносит каждый до исполнения и ждет вашего решения на развилках.

## Шаг 1: смотрю, что уже есть на машине

**Что я делаю:** проверяю версию Node и наличие git.

**Зачем:** Койз — это приборы на Node без единой зависимости. Нужен Node 20 или новее; больше
ничего ставить не придется, и это стоит подтвердить до начала, а не в середине.

**Что меняется на диске:** ничего. Две команды только читают.

**Что вы получите:** ответ «можно» или «сначала обновите Node», без догадок.

```bash
node --version
git --version
```

## Шаг 2: забираю дом

**Что я делаю:** клонирую репозиторий в выбранную вами папку.

**Зачем:** дальше все происходит внутри: приборы, ворота приемки и мутационные ворота лежат там.

**Что меняется на диске:** появляется одна новая папка. За ее пределами ничего не трогается.

**Что вы получите:** локальную копию инструмента целиком.

**Развилка:** есть git — беру `git clone`, обновление потом одной командой. Нет git — беру
архивом, но тогда обновляться придется повторным скачиванием.

```bash
git clone https://github.com/zarubinvibe/koiz.git && cd koiz
```

## Шаг 3: проверяю, что приборы не врут

**Что я делаю:** гоню селфтест, а затем мутационные ворота: они ломают девятнадцать правил по
копии и требуют, чтобы каждое роняло селфтест.

**Зачем:** селфтест, который остается зеленым при сломанном правиле, ничего не проверяет.
Прежде чем доверить инструменту свои уроки, стоит увидеть, что он судит себя всерьез.

**Что меняется на диске:** ничего за пределами временной папки, которая удаляется сама.

**Что вы получите:** две зеленые строки. Красная — не ставьте, откройте issue: значит инструмент
у вас работает не так, как заявлено.

```bash
node scripts/koiz.mjs --selftest
node scripts/koiz-mutate.mjs
```

## Шаг 4: завожу базу уроков

**Что я делаю:** создаю журнал уроков и, если у вас уже есть рукописный лог самообучения,
переношу его записи с проверкой, что ни одна не потерялась.

**Зачем:** база лежит ВНЕ репозитория — в `~/.claude/koiz/lessons.jsonl`. Уроки несут пути,
имена и куски команд, и в git такому не место. Журнал только дописывается: ничего не
перезаписывается и не стирается.

**Что меняется на диске:** появляется один файл в вашей домашней папке. Секреты в него не
попадают: фильтр стоит на записи, а не на выдаче.

**Что вы получите:** базу, которая ищется по классу ошибки, а не по имени репозитория, — урок из
одного проекта находится из другого.

**Развилка:** перенести существующий лог (`--file <путь>`) или начать с чистой базы. Перенос
ничего не портит: он только дописывает и в конце сверяет каждую запись по ее источнику.

```bash
node scripts/koiz.mjs migrate --file ~/.claude/self-learning/lessons.md
```

## Шаг 5: ставлю съем на закрытие сессии

**Что я делаю:** вшиваю хук `SessionEnd`, который на выходе из сессии снимает с транскрипта
упавшие команды, отказы ворот и трижды повторенные вызовы.

**Зачем:** урок, который надо записать руками, не записывается. Машина берет с диска то, что
видно без вас, и оставляет вам единственное, чего она не знает, — «почему так вышло».

**Что меняется на диске:** одна строка в настройках вашего агента. Хук тихий и не падающий:
он не может сломать выход из сессии.

**Что вы получите:** базу, которая пополняется сама, и список сырья, у которого надо дознать
причину.

**Развилка:** автоматически хуком или вручную командой `capture --transcript <файл>` после
сессии. Первое надежнее, второе не трогает ваши настройки.

```bash
node scripts/koiz.mjs capture --transcript ~/.claude/projects/<проект>/<сессия>.jsonl
```

## Шаг 6: спрашиваем базу и смотрим долги

**Что я делаю:** задаю базе вопрос вашими словами и показываю ворота долга.

**Зачем:** база доказывает себя не установкой, а ответом. Ворота отвечают на другой вопрос:
что уже повторилось дважды и до сих пор ничем не закреплено.

**Что меняется на диске:** ничего. Обе команды только читают.

**Что вы получите:** выдачу с полем «чем закреплено» у каждого урока и честный список долгов.
Код 1 у ворот означает: этот класс ошибки повторится снова, пока его не закроет механизм.

```bash
node scripts/koiz.mjs ask "о чем был урок"
node scripts/koiz.mjs debt
```
